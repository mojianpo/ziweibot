# 法务要点与引文处理（LEGAL_NOTES）

> 这份文档记录**实测**的合规现状与处置方式。
> 结论仅供参考，正式商用前请咨询法务。

---

## 1. 核心结论（一句话）

**解读数据集的「断语正文」是 CC BY 4.0（可商用、须署名），
但文本中引用的倪海厦《天纪》原话不在该授权范围内（CC BY-NC-SA 4.0，不可商用）。**

上游仓库在 `DATASET-LICENSE` 里写得很明确：

> 解读文本中引用的倪海厦《天纪》原话，是为说明断语出处而注明集数与时间码的
> 简短引用，著作权归原权利人，不属于本数据集的授权范围；要把这些原话单独成批
> 使用，按仓库 `docs/tianji-ziwei/LICENSE.md`（CC BY-NC-SA 4.0）处理。
> 《紫微斗数全书》等古籍原文属公有领域。

---

## 2. 实测：引文密度

用 `packages/citation-guard` 对 1990 年**前 600 张盘**（7,800 段维度文本）扫描：

| 指标 | 数值 |
|---|---|
| 文本总量 | 17,803,442 字 |
| 受限引文片段命中 | **34,667 处** |
| 含受限引文片段的维度文本 | **6,159 / 7,800 段（79.0%）** |
| 「倪师 / 倪海厦」出现次数 | 65,090 处 → 降级后保留 41,339 处（移除 23,751 处出处署名） |

**这说明「跳过引文块」不是边角情况，而是绝大多数解读都会碰到。**

### 数据集里引文的实际形态

```
这句不对：「那如果你看到煞星跟天府星在一起的时候，书上说天府星可以解厄制化……」
（倪海厦《天纪》第5集53:06）又说「这个天府星一定要逢到三台八座……」（第7集27:56）
```

```
· 〔倪师断法·格局〕【禄马交驰】会进很大的财 ——《天纪》p07 00:50:17
```

```
**关键推导**（倪师断法引擎 · 可回溯《天纪》）
```

```
· **天府五行属土**——传统以土应脾胃（倪师断疾厄先看通盘、……不作病断）。
```

四种形态：**显式《天纪》标注**、**定位符（p07 00:50:17 / 第5集53:06）**、
**整块标注（〔倪师断法·…〕）**、**署名标签（倪海厦 / 倪师）作为出处的一部分**。

注意最后一种和第三种括号里的「倪师」不是一回事 —— 见下一节。

## 3. 区分：哪些是「受限引文」，哪些是「数据集自有内容」

这点很重要，决定了降级时该丢什么。**判据是「与《天纪》标记是否紧邻绑定」**，
而不是「有没有出现倪师二字」。

| 内容 | 许可 | 处置 |
|---|---|---|
| 断语正文（对命盘的分析文字） | CC BY 4.0 | **保留**，署名即可 |
| 《紫微斗数全书》等古籍原文 | 公有领域 | **保留** |
| 倪师《天纪》原话（引号内的原话） | CC BY-NC-SA 4.0 | **降级/移除** |
| 定位符标注（`p05 00:49:01`、`第5集53:06`） | 本身是事实性出处标注 | 可保留，但**引用了出处就等于指认了受限内容**，一并降级 |
| `〔倪师断法·格局〕` 这类整块标记 | 指向受限语料体系 | 降级 |
| **与《天纪》标记紧邻的署名**（`倪海厦《天纪》`） | 受限内容的出处 | 降级 |
| **叙述句里的转述**（`倪师说天府是文官星`、`本平台批盘按倪师`） | CC BY 4.0（数据集自己的转述，非原话） | **保留** |
| **不含《天纪》标记的括号**（免责声明、口径说明） | CC BY 4.0 | **保留** |

### 为什么必须区分到这一层

早期版本把「倪师」二字一律当引文抹掉，实测产生三类破坏：

| 原文 | 旧输出 | 问题 |
|---|---|---|
| `但倪师说法不同：` | `但（引文略）法不同：` | 语义破碎 |
| `倪师说天府是文官星` | `（引文略）天府是文官星` | 语义破碎 |
| `传统以土应脾胃（倪师断疾厄…不作病断）` | `传统以土应脾胃（（引文略）断疾厄…不作病断）` | **免责声明被破坏**，且括号嵌套 |
| `（倪海厦《天纪》第5集53:06）` | `（（引文略））` | 括号不配对 |
| `——《天纪》p07 00:50:17` | `——（引文略）第5集` | 定位符前缀「第N集」漏网 |

现在按上表的分界重做，并把「降级后括号仍然配对」作为硬性回归指标
（见第 4 节与自测）。

## 4. 本项目的处置方式

实施简报第 3 节写的是：

> 不批量抽取、商用倪师《天纪》原话；展示层如遇明显引文块可降级为「略」或跳过

对应实现：`packages/citation-guard`

```ts
import { findCitations, redactCitations, redactByParagraph } from '@ziwei/citation-guard';

// 检测（返回的是**受限片段**，已合并相邻片段）
const hits = findCitations(text);      // CitationHit[]

// 降级：把引文块换成「（引文略）」，其余文字保留
const safe = redactCitations(text, 'inline');

// 降级：整行含引文的行丢掉
const safe = redactCitations(text, 'drop-line');

// 降级：按段落处理
const safe = redactByParagraph(text, 'inline');
```

### 三种降级模式

| 模式 | 行为 | 适用 |
|---|---|---|
| `inline` | 引文块 → `（引文略）`，其余不动 | 默认。保留可读性，同时移除受限原话 |
| `drop-line` | 含引文的行丢掉（纯引文行整行删） | 结构化断语列表 |
| `drop-block` | 整段丢弃 | 整段都是引文的情况 |

### 三条实现约束

1. **出处标注括号整体降级** —— `（倪海厦《天纪》第5集53:06）` 里的内容全部受限，
   整段替换为一个 `（引文略）`，不会出现 `（（引文略））`。
2. **括号内的局部替换用不带括号的占位符** —— 片段已经在某个括号内部时改用
   `引文略`，否则会产生嵌套括号。混合括号（受限部分 + 自有的免责声明）
   只替换受限部分，免责声明保留。
3. **不跨行合并相邻片段** —— 否则两条 bullet 行会被连成一个片段，
   第二行的行首符号被吞掉。

### MVP 的实际策略

1. **检索层原样返回**数据集文本（不改数据）
2. **展示层按需降级** —— Web 与 CLI 接入 `citation-guard`
3. 降级是**显式选择**，不自动改写 —— 避免悄悄改动内容
4. 自测：`npx tsx packages/citation-guard/src/selftest.ts`（25/25 通过，含真实数据回归）

### 真实数据回归指标

自测里对 1990 年前 200 盘逐段验证：

| 指标 | 要求 | 实测 |
|---|---|---|
| 降级引入的新括号破损 | 0 | 0 |
| 降级后残留《天纪》/定位符 | 0 | 0 |
| 降级丢失正文行 | 0 | 0 |
| 转述类「倪师」表述被保留 | > 0 | 13,942 处 |

## 5. 商用前必须做的事

如果本项目要**对外商业化**（收费、SaaS、公开运营），下列事项必须先完成：

| # | 事项 | 说明 |
|---|---|---|
| 1 | 确认展示层默认开启降级 | 商业场景必须默认 `inline` 降级，不能让受限原话直接对外 |
| 2 | 评估「断法正文」是否也构成衍生受限内容 | 断语由倪师体系生成，风格与判断均来自受限语料。**这是最大的不确定点** |
| 3 | 取得倪师引文的使用授权 | 若要原样展示，需按 CC BY-NC-SA 4.0 取得授权（不可商用，故商业化基本不可行） |
| 4 | 不再二次分发数据集本身 | 保持「本地检索」形态，不提供全量下载/镜像 |
| 5 | 保留完整署名 | 见 `ATTRIBUTION.md` 第 1 节 |
| 6 | 免责声明到位 | 见 `ATTRIBUTION.md` 第 4 节 |

> **第 2 项是本项目最大的法务不确定点。** 上游把数据集整体标为 CC BY 4.0
> 并声明「可用于商业用途」，但同时说明引文不在授权范围内。
> 「断语正文本身是否被视为受限内容的衍生作品」这个问题上游没有给出结论。
> 商业化前建议就此点单独取得书面意见。
